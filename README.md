**Software I'd show you**

- **[Scrivo](https://github.com/zohartito/scrivo)**: a free, open-source dictation app for Mac. Hold a key, speak,
  and the text lands where you're typing. Nothing leaves the computer.
- **[Local LLM Radar](https://local-llm-radar.vercel.app)**: a public website that shows which AI models fit a
  given computer and how they score on public benchmarks.
- **[Camera Autopilot](https://github.com/zohartito/camera-autopilot)**: software that runs my Sony cameras over USB.
  It meters a scene, sets the exposure and merges several shots into one photograph. Tested on an A7 II and an A7 III.

**Where the two meet**

pieces of the 1:24 model were packed onto 9 plywood sheets instead of 15, and the façade panels were rebuilt as
solids for 3D printing.
